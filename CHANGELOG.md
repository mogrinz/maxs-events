# Changelog

## v1.0.0 (initial public release)

- Self-hosted Raspberry Pi event boards with 20 configurable screen addresses.
- List and Detail layouts with landscape and portrait display support.
- Uploaded ICS calendars and subscribed iCalendar feeds, with source colors and screen assignments.
- Theme presets, uploadable custom CSS, and bundled offline-capable web fonts.
- 19 example ICS calendars for installation and testing.
- Optional local Wi-Fi hotspot, account management, backups, and documented Onn/Android TV kiosk setup.
- Consolidated `upgrade.sh` and `UPGRADING.md` for existing Max's Events installations.

The repository starts with clean Git history. Earlier internal prototype and release-candidate
history is retained separately in the private development archive.
