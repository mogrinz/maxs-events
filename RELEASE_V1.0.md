# Max's Events v1.0.0

Initial MIT-licensed release of Max's Events: a self-hosted digital event-board server for Raspberry Pi.

- 20 configurable event screens with `/display/screen1` through `/display/screen20` URLs.
- List and Detail views, landscape and portrait layouts, themes and custom CSS.
- Multiple uploaded ICS calendars or iCalendar URL subscriptions, source colors, and offline reuse of previously available data.
- Kiosk polls for calendar and configuration updates approximately every 15 seconds.
- Offline-capable self-hosted fonts, including all 64 required theme font variants and their license notices.
- 19 included ICS example files.
- Optional local Pi Wi-Fi hotspot and documented Onn Google TV kiosk/browser configuration, including a tested ADB reconnection workaround.

**For a new installation**, follow [README.md](README.md) and download the attached `maxs-events-v1.0-offline.zip`, rather than GitHub's automatic source archive. **For an upgrade**, back up the current installation and follow [UPGRADING.md](UPGRADING.md). Third-party fonts retain their respective licenses.
