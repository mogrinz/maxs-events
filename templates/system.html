Connection status, available Wi-Fi controls, and backup settings.

Enable Hotspot Support

This installation was originally configured without hotspot support. While connected through your normal Wi-Fi or Ethernet, back up the Pi, install the hotspot dependencies, then enable support without switching networks:

sudo apt install -y hostapd dnsmasq-base
cd ~/maxs-events
sudo python3 enable_hotspot_support.py

Refresh this System page after the helper completes. The Wi-Fi switching and confirmation controls are identical to Max’s Menu.
